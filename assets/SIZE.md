# Size Usage
- For anything above `128x128`, do not use the flat logo.
- For anything below `48x48`, do not use the nightly logo. Instead, use the regular logo (flat or not, depending on size), even if in a nightly version.
- For `16x16`, it's prefered to use the flat logo.
- For `32x32`, you may choose whether to use the flat logo or not.
- For anything above `32x32` but below `256x256`, it's highly recommended to go with the non-flat logo, but you may choose which to use.
- Always prefer SVG format when possible.
