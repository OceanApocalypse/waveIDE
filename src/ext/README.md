## About this project
**waveEXT** is **[waveIDE](../../README.md)**'s internally used extensibility system.

Despite being made for **waveIDE**, it can be used in any code editor.

**waveEXT** strives to be a powerful and versatile extensibility system for code editors that want to provide plugin support via out-of-process plugins.

> [!NOTE]
> It's worth mentioning **waveEXT** is split into parts: the protocol, which is fully editor-agnostic; and the manifest parsing logic, which follows waveIDE's manifest format.

### Editors using waveEXT
Below is a non-exhaustive list of editors that use **waveEXT** as their extensibility system.

- **[waveIDE](../../README.md):** a free and open-source code editor that aims to provide a versatile, fast and powerful editing experiencing while collecting no data from the user.
