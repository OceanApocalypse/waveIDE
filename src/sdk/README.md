## About this project
**waveSDK** is **[waveIDE](../../README.md)**'s plugin SDK. It provides an API plugin authors can effortlessly consume.

Under **waveIDE**, it is used alongside **[waveEXT](../ext/README.md)** to provide a powerful out-of-process plugin system.

Despite being made for **waveIDE**, it can be used in your own code editor, but it means you will have to implement everything **waveIDE**'s plugin API supports. Additionally, there's no specific guidance on how to do so, due to our focus being on waveIDE plugins.
